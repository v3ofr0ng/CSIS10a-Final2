# CSIS10a-Final2
Final project for CSIS10

The Project I chose was the Text Fighting Game. The objective of the game is beat the opponent using a variety of moves.
But the opponent will also attack with random moves. Whether the attack will land is completely random, but some moves are harder 
to execute than others. There is a risk and reward aspect of the game as to choosing attacks, and building off of previous attacks.
I hope to include random events, moves only available during certain situations, music, and maybe pictures too. Those last two are a 
maybe though.
